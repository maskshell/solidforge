## 0. 概述

- 项目代号: ios-reader（正式产品名后定，不阻塞任何验收标准）。
- 一句话定位: 面向个人的、本地优先的 iOS 原生电子书阅读器 —— EPUB/TXT/MOBI 导入阅读、深度排版定制、高亮笔记导出、iCloud 同步、BYOK AI 辅助。
- 平台: iPhone 优先（iOS 17+），iPad 同构适配。

## 1. JTBD（用户任务）

### 1.1 首位用户画像

开发者本人（个人自用产品，定位已确认）。重度中文阅读者；拥有多台 Apple 设备；重视数据自主权（笔记可导出、无平台锁定）；愿意为 AI 功能自行配置 API key；排斥广告、社交干扰与强制账号。

### 1.2 主任务（core job）

当我拿到一本 EPUB/TXT/MOBI 书时，我想立刻在 iPhone 上以我习惯的排版开始读、并从上次位置继续 —— 这样碎片时间都能变成阅读时间，不被工具摩擦打断。

### 1.3 支撑任务

- 集中管理: 当我的书散落在网盘、文件 App、AirDrop 时，我想把它们收进一个本地书架并可搜索分组，这样我总能在 10 秒内找到要读的书。
- 排版自主: 当长时间阅读时，我想把字号/行距/字体/主题调到眼睛舒服，这样单次阅读时长可以更长。
- 笔记沉淀: 当读到值得记录的段落时，我想划线批注并最终导出 Markdown 进个人知识库，这样阅读积累成为可复用资产而非平台内数据。
- 跨设备: 当我在 iPhone/iPad 间切换时，我想进度与笔记自动跟随，这样不需要回忆"读到哪了"。
- 语言与注意力辅助: 当遇到外文段落、长章节或想闭眼休息时，我想即时翻译/摘要/听书，这样阅读不被能力与场景卡住。

### 1.4 现有替代方案及其不满足点

- Apple Books: 不支持 MOBI；笔记导出能力弱；中文排版选项少。
- 微信读书: 平台锁定；广告与社交干扰；笔记迁出困难。
- KyBook / Marvin: 维护节奏不稳；中文排版质量不足。

本产品立足点: 本地优先 + 数据自主 + 中文排版质量 + BYOK AI。

## 2. 期望结果指标（desired outcome metrics）

结果指标而非功能清单；每条可观察、可测量，作为里程碑验收口径。

| 编号 | 指标 | 目标值 | 测量方式 |
| --- | --- | --- | --- |
| OM-1 | 续读直达 | 冷启动到恢复上次阅读位置 ≤ 2.5s | 近三年 iPhone 机型、书库 ≥100 本；Instruments/秒表采样 ≥5 次 |
| OM-2 | 导入顺畅 | EPUB(≤20MB) 导入到可读 ≤ 3s；TXT(50MB, GBK) ≤ 10s | 导入计时采样 ≥5 本 |
| OM-3 | 阅读流畅 | 翻页/滚动主线程掉帧率 < 1%，无可感知白屏 | Instruments Animation Hitches |
| OM-4 | 中文排版质量 | 行首不出现句读标点（。，、！？；：""等）；段首缩进两字宽；中英混排间距正确 | 排版用例集人工复核 + 快照比对 |
| OM-5 | 笔记资产化 | 全书笔记导出 Markdown 字段完整率 100%（书名/作者/章节/原文/批注/定位） | 导出文件脚本校验 |
| OM-6 | 多设备一致 | 两设备联网手动刷新后，进度/笔记差异为 0 | 双设备对照检查 |
| OM-7 | 可靠性 | 30 天自用零崩溃；除 AC-12 声明的冲突规则（最新时间戳胜出）所覆盖的落败写入外，零进度/笔记丢失 | 自用日志 |
| OM-8 | 隐私底线 | 未配置 AI key 且 iCloud 关闭时，应用自身外发网络请求为 0 | 抓包 / Instruments Network 验证 |

## 3. 范围边界（scope boundary）

### 3.1 范围内（in-scope）

按三个里程碑串行交付（依据 §4 约束 C1、决策 D7）:

- M1 阅读核心（可日常自用）: AC-1 至 AC-11 —— EPUB/TXT/MOBI 导入、书架管理、续读恢复、排版定制、主题、双翻页模式、阅读控制层、高亮批注、Markdown 导出；AC-16 性能门槛随 M1 一并验收。
- M2 同步: AC-12 —— iCloud 进度/笔记同步。
- M3 AI 辅助: AC-13 至 AC-15 —— 划词翻译、TTS 听书、章节摘要（BYOK）。

跨里程碑观测门槛: OM-7（可靠性）为 M1/M2 期间的持续自用观测项，随 M2 验收结算；OM-8（隐私底线）锚定于 AC-13（M3 验收），并在 M1 验收时先行执行一次（此时无任何 AI 代码路径，预期同样为 0）。

### 3.2 明确范围外（out-of-scope，本期不做）

- PDF 阅读（固定版式渲染为独立大模块；二期是否立项由人再决策，见 ODP-3）。
- 有声书（Audiobook）播放器。
- iPad 专属布局特化（仅同构适配）；Apple Watch / visionOS / macOS 版本。
- 在线书城、内容分发、社区/分享功能。
- 自建账号体系与自建服务器。
- 内购/订阅/广告等商业化模块。
- OPDS / Calibre 在线书库接入（二期候选，不承诺）。

## 4. 约束与假设（constraints and assumptions）

### 4.1 约束

- C1 单人业余开发，工时有限 → 三里程碑串行交付，每期结束可独立日常使用。
- C2 技术基线: SwiftUI、iOS 17+、SwiftData；iPhone 优先，iPad 同构适配（用户已确认）。
- C3 无自建服务器、无自建账号: 同步仅 iCloud/CloudKit 私有数据库；AI 仅用户自带 key（BYOK）访问第三方 API。
- C4 本地优先: iCloud 不可达时全部本地功能可用；同步是增强而非依赖。
- C5 合法边界: 不解析、不规避任何 DRM；书籍来源假设为用户合法自有。
- C6 界面语言: 简体中文优先（英文本地化后置，不入里程碑）。

### 4.2 假设

- A1 首位且唯一确定用户为开发者本人；书库规模 ≤ 2000 本，单本 TXT ≤ 100MB（超出可用，性能不承诺）。
- A2 用户愿意为 AI 功能自行获取并配置 API key；模型服务可用性不可控，故 AI 功能必须可完全降级（无 key 时引导配置或隐藏，不阻塞阅读）。
- A3 阅读内容以中文为主（排版质量指标以中文为基准）；EPUB 2/3 覆盖绝大多数书籍来源。
- A4 同一 Apple ID 下的各设备持有同一书目的相同文件副本（字节级一致；D4 的 MOBI→EPUB 转换在本书目内保持确定性复现）。AC-12 的同步正确性（进度/笔记定位到正确文本）以此为前提；副本不一致导致的定位偏移不计入同步缺陷（后续版本可考虑增加一致性校验，非本期承诺）。

## 5. 已做决策（decisions）

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | SwiftUI-only，最低 iOS 17 | 个人自用无兼容包袱；Observable / SwiftData 等新 API 降低长期维护成本（用户已确认） |
| D2 | 本地优先架构: SwiftData 本地主存储，CloudKit 为同步通道 | 数据自主是产品立身点；iCloud 私有库免服务器、免账号运营（C3/C4） |
| D3 | 分页渲染统一抽象为 PaginationRenderer 公共边界；EPUB 走 WebKit 分页、TXT 走原生 TextKit | 重排版与纯文本的性能/排版特征不同；抽象后两实现可替换，AC-8 模式切换有统一挂点 |
| D4 | MOBI/AZW3 导入时转换为 EPUB，不做运行时原生渲染 | KF8 与 EPUB 同源，转换路径成本远低于维护双渲染引擎 |
| D5 | 标注定位: EPUB 用 CFI、TXT 用字符偏移，统一封装为 AnnotationLocator | 跨格式统一笔记体系；排版参数变化后仍可重定位（AC-10 的成立前提） |
| D6 | AI 全部 BYOK，应用不内置任何模型服务与密钥 | 隐私底线与零运营成本（C3、OM-8） |
| D7 | 三里程碑 M1/M2/M3 串行交付，每期可独立使用 | 单人工时约束（C1）下控制风险 |
| D8 | 里程碑顺序: 同步（M2）先于 AI（M3） | 同步是"多设备续读"主任务的必要件；AI 是增强件 |

## 6. 验收标准（acceptance criteria）

每条可测试（XCTest / XCUITest 或人工可复核）。每条以 `— seam: <公共边界名>` 声明其公共替换边界（seam 是调用方实际依赖的公共边界，不是内部辅助；parallel-development 在 Phase-0 锁定该声明）。seam 后的一句 catch/miss 注记说明: 在该 seam 替换实现时，本条验收覆盖什么（catch）、不覆盖什么（miss）。

- AC-1 EPUB 导入: 通过系统文件选择器、"文件"App 分享、AirDrop 三种途径导入 .epub；解析书名/作者/封面并在 3s 内出现在书架；重复导入同一本书合并条目而非重复建卡。— seam: BookImportPipeline（catch: 更换或扩展解析实现不波及书架与阅读层；miss: 不覆盖导入入口的 UI 交互编排）
- AC-2 TXT 导入: 导入 .txt 自动检测编码（UTF-8 / GBK / GB18030 / UTF-16），50MB 文件 10s 内完成解析；按正则识别"第X章/卷/节"等常见模式智能切分章节，无法识别时按固定长度分节。— seam: BookImportPipeline（catch: 换解析实现不影响书架与阅读层；miss: 不覆盖章节识别规则本身的调参）
- AC-3 MOBI/AZW3 导入: 导入 .mobi / .azw3 时先转换为 EPUB 再入库并可正常阅读；转换失败给出可理解的失败原因，且保留原文件不删。— seam: BookImportPipeline（catch: 替换转换器不影响后续阅读链路；miss: 不覆盖各 MOBI 变体的兼容细节）
- AC-4 书架管理: 书架支持按书名/作者搜索、自定义分组、排序（最近阅读/书名/导入时间）、删除；删除书籍时默认保留其笔记，直到用户显式确认清除。— seam: BookLibraryService（catch: 存储实现更换不影响书架 UI 与阅读层；miss: 不定义列表滚动渲染细节）
- AC-5 续读恢复: 重新打开任意一本书，定位到上次阅读位置 —— EPUB 精确到段落级（CFI），TXT 精确到字符偏移 ±50 字符。— seam: ReadingProgressStore（catch: 进度存储迁移不改阅读层调用；miss: 不校验目标位置仍有效，越界兜底归渲染层）
- AC-6 排版定制实时生效: 字号（12–36pt）、行距（1.0–2.2 倍）、页边距、字体（系统内置 + 用户导入字体）任一调整后 200ms 内重排生效；中文排版满足 OM-4（行首无句读标点、段首缩进两字宽）。— seam: TypographyThemeEngine（catch: 渲染引擎更换仍消费同一套排版参数；miss: 不约束引擎内部的测量与断行实现）
- AC-7 主题: 内置白 / 米黄 / 深黑三档主题，支持自定义背景色与文字色；深色模式跟随系统切换，无需重启应用。— seam: TypographyThemeEngine（catch: 主题体系扩展不动渲染引擎；miss: 不覆盖主题取色的美术标准）
- AC-8 双翻页模式: 支持上下滚动与左右翻页两种模式，可随时切换且切换后保持当前位置；翻页无可感知白屏闪烁（OM-3）。— seam: PaginationRenderer（catch: WebKit 与 TextKit 两实现可互相替换；miss: 不定义翻页动画的美术形态，见 ODP-1）
- AC-9 阅读控制层: 阅读中点按屏幕中央区域切换显示/隐藏控制层（进度条、目录、设置、书内搜索）；点按左/右侧区域执行前/后翻页。— seam: ReaderShell（catch: 控制层整体替换不触及渲染引擎；miss: 不覆盖手势识别的具体参数与阈值）
- AC-10 高亮与批注: 选中文本可设置不少于 3 色高亮并可添加批注；高亮跨应用重启保留；排版参数（字号/行距/字体）改变后高亮仍定位到正确文本。— seam: AnnotationStore（catch: 标注存储在本地与 CloudKit 间更换不影响交互层；miss: 不约束选区高亮的视觉渲染方式）
- AC-11 笔记导出: 全书高亮与批注一键导出为 Markdown（含书名/作者/章节/原文/批注/定位），通过系统分享面板导出；字段完整率满足 OM-5。— seam: AnnotationStore（catch: 导出格式扩展不改标注数据模型；miss: 不覆盖分享面板的系统行为）
- AC-12 iCloud 同步: 同一 Apple ID 的两台设备间，进度/高亮/批注经 CloudKit 同步；两端手动刷新后数据一致（OM-6）；冲突以最新时间戳胜出，冲突落败方的写入按此规则被覆盖（该覆盖不计入 OM-7 的"丢失"）；iCloud 关闭或不可达时本地功能完全可用（C4）；同步正确性以 A4（各设备同书同副本）为前提。— seam: CloudSyncEngine（catch: 未来更换同步通道不动业务层；miss: 不处理各端同步状态的 UI 展示细节）
- AC-13 划词翻译: 选中文本弹出"翻译"入口；未配置 AI key 时跳转配置引导页而非报错；未配置 AI key 且 iCloud 关闭时，应用自身外发网络请求为 0（OM-8 隐私底线）；已配置时返回译文并与原文对照展示。— seam: AIReadingService（catch: 更换模型供应商只改适配器；miss: 不覆盖各供应商 API 的差异化细节）
- AC-14 TTS 听书: 从当前页开始朗读，朗读至页尾自动翻页（滚动模式自动下滚）；可暂停/继续/停止，语速可调。— seam: AIReadingService（catch: 朗读引擎在系统 Speech 与模型 TTS 间替换不动播放控制层，见 ODP-2；miss: 不覆盖语音合成的音色质量）
- AC-15 章节摘要: 对当前章节生成摘要（调用已配置模型）；无 key 或网络失败时给出可理解提示，不影响阅读主流程（A2 降级要求）。— seam: AIReadingService（catch: 摘要提示词与模型更换不动阅读主流程；miss: 不评价摘要内容质量 —— 结果轴归人）
- AC-16 启动性能: 冷启动到恢复上次阅读书籍的位置 ≤ 2.5s（OM-1；近三年 iPhone 机型、书库 ≥100 本）。— seam: ReaderShell（catch: 启动装配路径重构不改各模块公共接口；miss: 不覆盖各模块内部的首帧优化手段）

## 7. 非目标（non-goals）

非目标 = 产品理念上不追求的方向。与 §3.2 的区别: 范围外是"本期不做、以后可议"，非目标是"不作为本产品方向"。

- NG-1 不做 DRM 破解或任何版权规避功能（永久，C5）。
- NG-2 不做自建服务器、自建账号、社交体系（永久；产品定位为本地优先个人工具）。
- NG-3 不做内容分发 / 书城（永久）。
- NG-4 不以商业化为目标（v1 无内购无广告；若启动商业化需重开本 spec）。
- NG-5 不追求跨平台（仅 iOS/iPadOS）。
- NG-6 不追求全格式通吃: 以 EPUB/TXT 为核心质量标杆，MOBI 走转换路径；不为长尾格式稀释核心排版质量投入。
